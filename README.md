Learning Path Stress Tester is a simulation-based tool that evaluates how well a learning plan holds up under real-world conditions such as limited time, drops in motivation, 
and changing market demands. It takes a structured plan (topics, timelines, dependencies) and runs stress scenarios to mimic disruptions like inconsistent study schedules, 
reduced availability, and shifting skill relevance. The system then outputs a robustness score along with key failure points, such as unrealistic timelines, bottlenecks, or 
over-reliance on consistency, helping users design more resilient, flexible, and practical learning strategies before execution.
